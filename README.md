Инструмент для проверки валидности номеров телефона и email адресов, а так же есть функция для поиска информации о домене.

Как запустить инструмент?

Скачиваете папку дальше открываете терминал, пропишите там команду cd <путь>, и внутрий его команду pip install -r requirements.txt
После чего начнется загрузка библотек, не закрывайте окну !
Как только загрузкат завершиться пропишите команду python validator_tool.py
